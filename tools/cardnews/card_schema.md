# 카드뉴스 콘텐츠 JSON 스키마 (v2)

> 작가(Writer) 에이전트가 산출하는 카드 1장의 콘텐츠 명세.
> **JSON의 모든 필드는 작가가 책임지고 채운다** (파이썬 코드가 채워주는 필드 없음).
> 렌더링: `python tools/build_cardnews.py <이 스키마의 json>` → HTML/PNG (1080×1240).
> 넘침 검사: `python tools/build_cardnews.py <json> --check` (실제 렌더로 기계 판정)
>
> **이 파일이 카드 규격의 단일 원천이다.** 오케스트레이터·테스트 하네스가 카드 작성 지시문에
> 이 파일 전문을 첨부해 작가에게 전달한다 (writer.md에는 중복 기재하지 않음 — 토큰 절약 겸 규격 이원화 방지).
>
> v2 변경: 상자형 키워드 요약(눈썹문구+2줄 헤드라인+제목·설명 상자)을 폐지하고,
> **불릿 + 완전한 문장** 구조로 바꿨다. "3~5줄 키워드 나열이 지나치게 압축적"이라는 피드백 반영.
> 아래 자수·줄수 한도는 전부 실측값이다(Pretendard 실제 렌더 폭 기준, 2026-07-13 계측).

## 카드 구조 (위에서 아래로)

1. 헤더: `category · article_no` + `week_label` 배지
2. 제목 `title` (한 줄) + 부제 `subhead` + 강조색 구분선
3. 본문: 불릿 `points` **최대** 4~5개 — 각각 완전한 문장 1개(핵심 구절 형광펜 강조), 필요시 보조 설명
4. 푸터: 출처 `source` 3줄 + "AI TREND BRIEF" 로고
   ※ 'AI로 초안 작성 후 검수' 고지문은 **템플릿에 고정**되어 있다 — 작가가 쓰지 않는다.

## 필드 정의

| 필드 | 형식 | 규격 | 예시 |
|---|---|---|---|
| `category` | 문자열 | `정책` / `기술` / `윤리` 중 하나 (강조색 자동 결정) | `"정책"` |
| `article_no` | 문자열 | 두 자리 항목 번호 | `"01"` |
| `week_label` | 문자열 | `M월 N주` 형식 | `"7월 2주"` |
| `title` | 문자열 | **한 줄 고정(넘치면 잘림!). 환산 ≤ 17자** | `"UN, ‘킬러 로봇’ 국제 통제 촉구"` (환산 15.4자) |
| `subhead` | 문자열 | **환산 ≤ 78자** (1~2줄). 제목을 보충하는 한 문장 | |
| `points` | 배열 **최대 5개** (권장 4개) | 항목마다 `{pre, key, post, sub}` — 아래 상세 | |
| `points[].pre` | 문자열 | 문장 앞부분 (key 앞까지) | |
| `points[].key` | 문자열, **선택** | 형광펜 강조 구절. **환산 ≤ 25자**, 문장의 1/3 이하. 문장당 1개 | |
| `points[].post` | 문자열, **선택** | 문장 뒷부분. **key가 없으면 post도 쓰지 않는다** — 문장 전체를 pre에 담는다 | |
| `points[].sub` | 문자열 **또는 배열**, 선택 | 대시(—)로 붙는 보조 설명. **각각 환산 ≤ 46자(1줄)**. 한 포인트에 여러 개면 배열로 | |
| `source` | 배열, **정확히 3줄** | 아래 고정 형식 | |

## 환산 자수 (모든 자수 한도의 기준)

폭이 다른 글자를 실측 비율로 환산해서 센다 (한 줄에 들어가는 양을 정확히 반영):

> **환산 자수 = 한글·한자 1자 + 공백 0.3자 + 영문·숫자·문장부호 0.6자**

- 근거: 실측 자폭(24px 기준) — 한글 20.7px, 영문 12.8px(0.62배), 공백 5.9px(0.29배)
- 감으로는: 순한글 문장이면 그냥 글자 수, 영문이 섞이면 실제보다 여유가 생긴다
- 정확한 판정은 기계가 한다 (`validate_card` + `--check`) — 작가는 대략 맞춘 뒤 검사 결과를 따른다

## 본문 분량 규칙 (실측 근거)

- **분량 하한은 없다.** 내용이 적으면 본문과 푸터 사이가 비어 보일 뿐이며, 이는 허용된 디자인이다.
  원문이 짧으면 억지로 채우지 말 것. **관리 대상은 최대값(넘침)뿐이다.**
- **한 문장 = `pre`+`key`+`post`를 이어 붙인 것.** 환산 **≤ 126자**, **권장 50~84자(=2줄)**.
  구판처럼 키워드만 나열하지 말고 완전한 문장으로 쓴다.
- 문장 줄수 = 환산 자수 ÷ 42 (올림). 즉 **≤42자=1줄, ≤84자=2줄, ≤126자=3줄**.
- **줄수 검산: Σ(각 문장의 줄수) + (보조 설명 개수) ≤ 14** 를 저장 전에 확인한다.
  **보조 설명이 4개 이상이면 한도는 13** (보조 한 줄 44px이 문장 한 줄 36px보다 약간 비싸서).
  - 근거: 본문 세로 예산 688px(부제 2줄 기준) = 문장 1줄 36px, 보조 1줄 33px+간격 11px, 불릿 간격 35px.
  - 예: 3줄 문장 3개 + 2줄 문장 2개 + 보조 1개 = 9+4+1 = 14 → 합격(꽉 찬 카드).
  - 이 예산 안에서 **포인트와 보조는 서로 교환 가능** — 보조가 많은 기사면 포인트 수를 줄이면 된다.
- 문장은 개조식 완결형으로 끝낸다: `…촉구함.` `…강조함.` `…규정함.`

## source 3줄 고정 형식

```json
"source": [
  "원문 제목 : From AI to ‘killer robots’: UN chief issues urgent governance call",
  "발간처(발간일) : UN News(26.07.06.)",
  "URL : news.un.org/en/story/2026/07/1167873"
]
```

- 1줄 `원문 제목 : {원제 그대로}` — 90자를 넘으면 뒷부분을 `…`로 줄인다 (한 줄 고정이라 길면 잘림)
- 2줄 `발간처(발간일) : {매체}({YY.MM.DD.})` — 월·일 두 자리, 끝에 마침표
- 3줄 `URL : {프로토콜(https://) 뗀 URL}`
- 발간일이 명확하지 않은 소스(정책 안내 페이지 등)는 날짜를 생략하지 말고,
  **발효일·적용일 같은 대표 날짜를 일(日)까지 채워** 표기 (예: EU AI법 전면 적용 '26.8.2. → `26.08.02.`)

## 콘텐츠 규칙

1. **새 사실 금지** — 카드의 모든 내용은 주어진 원문 자료에 근거한다. 자료에 없는 사실·수치를 추가하지 않는다.
2. **줄바꿈은 단어 단위** — 템플릿 CSS(`word-break: keep-all`)가 보장하므로 작가는 신경 쓰지 않는다.
   단, 띄어쓰기 없는 초장문 단어(URL 등)를 본문에 넣으면 안 된다.
3. **규격 위반은 기계 검사로 판정** — 자수 규격과 렌더 실측(넘침·제목 잘림)을 합친
   `build_cardnews.py --check`가 판정한다. 사람 눈에 의존하지 않음.
   검토자가 카드마다 이 명령을 실행해 결과를 review.md 에 기록하고, 불합격은 반려 사유가 된다.
4. **저장 전 자체 검산** — 작가는 저장 전에 자수·개수·줄수 합계를 스스로 검산한다.

## 전체 예시 (구조 참고 — 실측 검사 통과본)

```json
{
  "category": "정책",
  "article_no": "01",
  "week_label": "7월 2주",
  "title": "UN, ‘킬러 로봇’ 국제 통제 촉구",
  "subhead": "제네바에서 첫 ‘AI 거버넌스 글로벌 대화’ 개막 — 구속력 있는 국제 규범과 ‘인간 통제’ 원칙을 강조",
  "points": [
    {
      "pre": "그는 “기계는 정보를 제공할 수 있어도 결정과 그에 대한 책임은 인간의 몫”이라며, 모든 AI 활용에서 ",
      "key": "인간 통제(human-in-the-loop) 원칙",
      "post": "이 지켜져야 한다고 강조함."
    },
    {
      "pre": "안토니우 구테흐스 UN 사무총장이 첫 ‘AI 거버넌스 글로벌 대화’에서 구속력 있는 국제 통제를 촉구함.",
      "sub": "이 협의체는 UN 최초의 상설 AI 거버넌스 기구로, 2차 회의는 2027년 5월 뉴욕에서 열릴 예정임."
    }
  ],
  "source": [
    "원문 제목 : From AI to ‘killer robots’: UN chief issues urgent governance call",
    "발간처(발간일) : UN News(26.07.06.)",
    "URL : news.un.org/en/story/2026/07/1167873"
  ]
}
```

(위 points는 형식 예시로 2개만 실었다 — 실제 카드는 4~5개. key가 있는 문장(1번)과
key 없이 pre에 문장 전체를 담은 경우(2번), sub가 붙는 경우(2번)를 보여준다.
보조 설명이 한 포인트에 여러 개면 `"sub": ["첫째 …", "둘째 …"]`처럼 배열로 쓴다.
완성 견본: `data/tests/cardnews/card_v2_sample.json`)
