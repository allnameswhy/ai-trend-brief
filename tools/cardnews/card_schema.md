# 카드뉴스 콘텐츠 JSON 스키마 (v1)

> 작가(Writer) 에이전트가 산출하는 카드 1장의 콘텐츠 명세.
> **JSON의 모든 필드는 작가가 책임지고 채운다** (파이썬 코드가 채워주는 필드 없음).
> 렌더링: `python tools/build_cardnews.py <이 스키마의 json>` → HTML/PNG (1080×1240).
> 견본: `demo_card.json` (이 스키마의 정답 예시)

## 필드 정의

| 필드 | 형식 | 규격 | 예시 |
|---|---|---|---|
| `category` | 문자열 | `정책` / `기술` / `윤리` 중 하나 (강조색 자동 결정) | `"정책"` |
| `article_no` | 문자열 | 두 자리 항목 번호 | `"02"` |
| `week_label` | 문자열 | `M월 N주` 형식 | `"7월 2주"` |
| `eyebrow` | 문자열 | **≤ 25자**, 한 줄. 기사를 한 구절로 압축 | `"트럼프, AI 행정명령 서명"` |
| `headline` | **배열 1~2줄** | **각 줄 ≤ 12자** (76px 대형 활자의 물리적 한계). 줄바꿈 위치도 작가가 결정 | `["美, AI 규제 대신", "'자율'을 택했다"]` |
| `subhead` | 문자열 | **≤ 70자** (약 2줄). 헤드라인을 보충하는 한 문장 | |
| `points` | 배열 **2~5개** | 항목마다 `{title, desc}`. 기본 3개 권장 | |
| `points[].title` | 문자열 | **≤ 22자**, 한 줄 | |
| `points[].desc` | 문자열 | **≤ 60자** (1~2줄) | |
| `source` | **배열, 항상 정확히 3줄** | 아래 고정 형식 | |

## source 3줄 고정 형식

```json
"source": [
  "출처 : {매체}({Mon.}, {YYYY}), {영문 원제}",
  "원문 : {URL 또는 축약 URL}",
  "발간일 : {YY.MM.DD.}"
]
```

- 월 표기는 영문 약어 + 마침표: `Jan.` `Feb.` `Mar.` `Apr.` `May` `Jun.` `Jul.` `Aug.` `Sep.` `Oct.` `Nov.` `Dec.`
- 1줄: `출처 : The White House(Jun., 2026), Promoting Advanced Artificial Intelligence Innovation and Security`
- 2줄: `원문 : whitehouse.gov/presidential-actions`
- 3줄: `발간일 : 26.06.02.` — 반드시 `YY.MM.DD.` 형식 (월·일 두 자리, 끝에 마침표)
- 발간일이 명확하지 않은 소스(정책 안내 페이지 등)는 날짜를 생략하지 말고,
  **발효일·적용일 같은 대표 날짜를 일(日)까지 채워** 표기 (예: EU AI법 전면 적용 '26.8.2. → `26.08.02.`)

## 콘텐츠 규칙

1. **새 사실 금지** — 카드는 이미 작성한 원고(item.md)의 압축본. 원고에 없는 사실·수치를 추가하지 않는다.
2. **줄바꿈은 단어 단위** — subhead는 단어 중간에서 줄이 꺾이지 않는다 (템플릿 CSS `word-break: keep-all`이 보장. headline은 작가가 배열로 직접 줄을 나눔).
3. **규격 위반은 기계 검사로 판정** — 필드 존재·개수·글자 수를 테스트 하네스가 검사한다 (사람 눈에 의존하지 않음).
